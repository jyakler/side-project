# 01 — 지도로 정한 목적지의 반경 진입 알림

## Outcome

사용자가 앱을 열면 바로 지도가 보이고, 핀을 찍어 목적지를 여러 개 두고 목적지마다 반경을 조절합니다. 주소나 장소를 검색하면 그 위치로 지도가 이동하고 찾은 이름이 보입니다. 가동하면 기기가 줄 수 있는 최대 정확도로 위치를 추적하고, 반경에 처음 들어온 목적지의 알림이 사용자가 끄기 또는 보류를 고를 때까지 이어집니다. 알림 상태는 목적지마다 독립적입니다. 이 작업은 웹 화면에서 끝까지 동작하고 검증됩니다.

## Blockers

None.

## Acceptance criteria

- [x] 지도에서 핀을 찍고 반경을 정해 목적지를 여러 개 만들 수 있고, 반경이 지도에 원으로 보입니다.
- [x] 주소나 장소를 검색하면 지도가 그 위치로 이동하고 찾은 이름이 보입니다. 결과가 없으면 그 사실이 보입니다.
- [x] 목적지가 하나 이상일 때 가동하면 가동 중 상태와 목적지별 남은 거리가 보입니다. 가동 전에는 위치 추적과 알림이 일어나지 않습니다.
- [x] 목적지가 없거나 반경이 유효하지 않으면 가동되지 않고 이유가 보입니다. 위치 권한이 거부되면 가동하지 않고 안내합니다.
- [x] 위치가 목적지 반경 밖에서 안으로 처음 들어오면 그 목적지의 알림이 발생하고, 끄기나 보류를 고르기 전에는 이어집니다.
- [x] 끄기를 고르면 알림이 멈추고, 그 목적지에서는 반경을 벗어났다 다시 들어와도 알림이 뜨지 않습니다.
- [x] 보류를 고르면 알림이 멈추고, 반경을 확실히 벗어난 뒤(반경의 20%를 더 벗어난 거리) 다시 들어올 때 알림이 다시 발생합니다. 반경 안에 머무는 동안에는 다시 울리지 않습니다.
- [x] 경계 근처에서 위치가 안팎을 오가도 알림이 발생했다 꺼지고 다시 발생하기를 반복하지 않습니다.
- [x] 한 목적지의 알림을 끄거나 보류해도 다른 목적지의 알림은 빠지지 않고 각 영역에 들어갈 때마다 발생합니다.
- [x] 중지하면 위치 추적과 알림이 모두 멈춥니다.
- [x] 이 서비스가 운영하는 서버 없이 목적지와 설정이 기기에만 저장되고, 사용자 위치와 목적지는 외부로 전송되지 않습니다.

## Constraints

- 지도와 주소 검색은 키 없이 쓰는 Leaflet, OpenStreetMap 타일, Nominatim 검색을 씁니다. 이 선택의 이유와 재검토 조건은 [map-provider](../../../decisions/map-provider.md)가 다룹니다.
- 화면은 [ui-composition](../../../decisions/ui-composition.md)을 따릅니다. 지도는 custom UI로 만들 수 있고 그 안의 일반 control은 shadcn 구성을 유지합니다.
- 알림의 소리와 진동은 웹이 허용하는 범위에서만 냅니다. 방해금지와 무음 정책은 02가 맡습니다.

## Verification

- 반경 진입 판정을 위치 순서 입력으로 확인하는 단위 테스트가 통과합니다: 첫 진입 알림, 끄기 뒤 재진입 무알림, 보류 뒤 이탈 후 재진입 재알림, 경계 흔들림 무반복, 목적지 독립.
- 실행 중인 앱에서 위치를 흉내 내어 넣어(`next-dev-loop` 스킬) 지도에서 핀 찍기와 주소 검색, 목적지 추가, 가동, 반경 진입 알림, 끄기와 보류, 중지가 기대대로 동작하는지 확인합니다.
