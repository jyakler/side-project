# 02 — 앱이 백그라운드이거나 화면이 꺼져도 오는 알림

## Outcome

사용자가 앱을 Capacitor 네이티브 앱으로 설치해 가동하면, 앱이 백그라운드에 있거나 화면이 꺼져 있어도 반경에 들어온 순간 소리, 진동, 알림으로 알립니다. 방해금지에서는 팝업만, 무음에서는 기기가 허용하면 진동만 내고 허용하지 않으면 팝업만 냅니다. 지도와 주소 검색은 앱 안에서도 동작합니다.

## Blockers

화면 꺼짐, 방해금지, 무음 확인 — adb를 쓸 수 없고 에뮬레이터 콘솔의 전원 키 입력이 전달되지 않아 화면을 끌 수 없습니다. 소리와 진동은 화면 캡처로 판별할 수 없습니다. 사용자가 에뮬레이터 창이나 실기기에서 직접 확인해야 합니다.

## Acceptance criteria

- [x] 가동 후 앱이 백그라운드에 있어도 반경 진입 알림이 옵니다.
- [ ] 가동 후 화면이 꺼져 있어도 반경 진입 알림이 옵니다.
- [ ] 방해금지 모드에서는 팝업만 뜨고 소리와 진동은 없습니다.
- [ ] 무음 모드에서는 기기 정책이 앱의 진동을 허용하면 진동만 내고, 허용하지 않으면 팝업만 뜹니다.
- [x] 백그라운드에서 온 알림에서도 끄기와 보류를 고를 수 있고, 01과 같은 결과가 나옵니다.
- [x] 지도와 주소 검색이 앱 WebView 안에서 동작합니다.
- [x] 앱을 실행하면 지도보다 먼저 OS 권한 창으로 알림과 정확한 위치 권한을 받고, 정확한 위치가 허용되지 않으면 이유와 설정 이동을 안내합니다(2026-10-22 사용자 요청).

## Constraints

- 제공 형태는 Capacitor 네이티브 앱이고, 위치 추적은 MIT 라이선스인 `@capacitor-community/background-geolocation`의 백그라운드 위치 갱신과 01의 JS 판정을 씁니다. 이유와 재검토 조건은 [delivery-form](../../../decisions/delivery-form.md)이 다룹니다.
- 방해금지와 무음은 사용자가 기기에 정한 의사이므로 앱이 뚫지 않습니다.
- 사용자가 앱을 강제 종료한 상태의 알림은 보장하지 않습니다.
- "끌 때까지 계속 울림"이 OS의 알림 방식 때문에 한 번 울리고 끝날 수 있습니다. 기기에서 한계가 확인되면 임의로 넘기지 말고 스펙의 범위를 다시 정합니다.

## Verification

- 앱 빌드와 네이티브 프로젝트 동기화가 성공합니다.
- Android 에뮬레이터의 이동 경로 재생 또는 실제 Android 기기에서, 앱을 백그라운드로 보내고 화면을 끈 채 반경에 진입시켜 알림이 오는지, 방해금지와 무음 상태의 알림 형태가 기대와 같은지, 지도가 앱 안에서 뜨는지 확인합니다. 이 PC에는 Android SDK가 없으므로 에뮬레이터 설치나 기기 연결이 먼저 필요하고, 그 전에는 이 작업을 완료로 표시하지 않습니다.

## Review checkpoint

None.

## Status

blocked

## Execution

- Verification: 2026-10-22 adb 없이 에뮬레이터(AVD `arrival35`, Android 35)에서 확인했습니다. APK는 PC의 HTTP 서버에서 에뮬레이터 Chrome으로 내려받아 설치했고(링크는 에뮬레이터 콘솔 `sms send`로 전달), 위치는 콘솔 `geo fix`로 넣었습니다. 앱 실행 시 알림 → 위치 권한 창 순서, 대략적인 위치만 허용하면 차단과 안내, 다시 요청 시 정확한 위치 변경 창, 허용 뒤 `/app` 지도 표시, 현재 위치 버튼(네이티브), 가동, 홈으로 보낸 뒤 상시 알림 "도착 알림 가동 중", 백그라운드 반경 진입 시 시스템 알림(끄기/보류 버튼), 알림의 보류와 끄기가 앱 상태(보류/꺼짐)에 반영되고 끈 뒤 재진입 무알림을 확인했습니다.
- Blocker: 2026-10-22 화면 꺼짐, 방해금지, 무음 상태의 알림 형태는 미확인입니다(위 Blockers).
- Revision: 2026-10-22 권한: 플러그인은 watcher 추가 시점에만 포그라운드 서비스를 시작하고, 위치 권한이 없으면 그 시작이 조용히 실패합니다. 그래서 앱 실행 시 `PermissionGate`가 알림과 정확한 위치 권한을 먼저 받고, watcher는 `requestPermissions: false`로 추가합니다.
- Revision: 2026-10-22 빌드 환경: JDK는 설치된 Corretto 25만 쓰므로 Gradle wrapper를 9.1.0으로 올리고, `android/build.gradle`에서 플러그인의 JDK 21 toolchain을 JDK 25 컴파일러(바이트코드는 Java 21)로 덮어썼습니다. Windows에서 Java 25의 소켓 경로 제한 때문에 `JAVA_TOOL_OPTIONS=-Djdk.net.unixdomain.tmpdir=D:\jt`가 필요합니다. 앱 시작 경로는 `server.appStartPath: "app.html"`입니다.
- Revision: 2026-10-22 지도 제공자를 키 없는 OpenStreetMap 계열로 바꾸면서 Kakao WebView 인증 항목을 "지도와 검색이 앱 WebView에서 동작"으로 바꿨습니다.
